## ✨ Key Features

- **Rolling dice:** Choose between a d6 or a d20.
- **Animations:** Smooth drawable animations during rolls.
- **History:** Saves previous roll results.

## 🛠️ Technologies

- **Language:** Java
- **User Interface (UI):** XML Layouts
- **Data Storage:** SharedPreferences
- **Environment:** Android Studio (Min SDK: 24 / Target SDK: 36)
